What this page settles, and what it does not

Nine of thirteen venues agree with the names transcribed in FL-112. For these games the game centre and the parameter values give the same stadium.

Three disagree. W11-01 Indianapolis at Houston is printed as Reliant Stadium on its game centre; the parameter reads "NRG Stadium". W11-07 Arizona at Kansas City is printed as Arrowhead Stadium; the parameter reads "GEHA Field at Arrowhead Stadium". W11-13 Cincinnati at Washington is printed as Northwest Stadium; the parameter reads "FedEx Field". The game centre prints the stadium in its own Game Info block for that game, so it is the reading shown here. The parameter is a hotel-link value and is not a stadium field. Which reading the public schedule should carry is a decision for the owner, logged as FL-118.

W11-12 Minnesota at San Francisco is played in Mexico City, at Estadio Banorte. It is a neutral-site game, and the game centre prints it that way. FL-112 does not list it.
