# Requirements Register
> Every requirement this project has to satisfy, in one tracked file, each one traced to the page that satisfies it and a status that says honestly how far it got.

The repository contained **no** requirements document when this session started — one 6-byte README and one commit. The brief lived only in the conversation, which is not an addressable source of truth for a system that is supposed to outlive a session. This register is the durable copy: {{metric requirements}} requirements, derived from the brief line by line, with the traceability column filled in from the actual state of the build.

The two right-hand columns make this the **decision-readiness table**: `Gate that blocks it` names an applicable internal validation gate (from `data/gates.csv`), and `Number that clears it` records the pre-specified condition or threshold where one exists. A `—` means no technical gate or numeric threshold is defined in the project register; it is not a claim that an item is fact-checked.

> **Source class:** Requirement wording, statuses, gate mappings, thresholds and clearing conditions are project design derived from the owner's brief and repository design records. They are **not official NFL facts** and are not verified by NFL sources. The `Origin` column shows where each register entry was raised, including later session/audit additions; the Source link preserves the owner-instruction register reference, not an official league citation. Factual NFL data is sourced separately in its own tables and flags. `done` means the project artefact exists and was checked, not that an NFL fact was confirmed. `specified` means the design is written; `partial` means a required element is missing and flagged; `pending` means an owner or later-session action.

## Depth coverage: two different counts

R-20, R-21 and R-44 describe a **10-chart personnel-relief join** against the 2026-11-13 Week 10 injury snapshot, resolving 85 of 296 filings. This is a join result, not an NFL-published total. The separate S745 register transcribes **31 of 32 club-published unofficial depth-chart pages** from its 2026-11-13 read; Houston's [official club page](https://www.houstontexans.com/team/depth-chart) displays a chart image that was not transcribed. A chart-page transcription count does not establish a point-in-time injured-starter replacement join for 31 clubs. Review the [Personnel Relief join](personnel-relief.html), [Depth Register and its row-level chart links](depth-deficiencies.html), [official NFL injury hub](https://www.nfl.com/injuries/), and the existing [FL-44 / FL-60 flags](flagged-for-review.html).
