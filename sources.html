Verification method (line by line)

  1. Fetch the official page and transcribe each row exactly (W-L-T, PF/PA, times, designations).
  2. Attach the source link to the row — no row without a link ships.
  3. Cross-check counts: 32 standings rows = 32 teams; 13 Week 11 games + 6 byes = 32; 6 injury designations match the summary article.
  4. Leave blanks where the source is silent (e.g. depth charts, market odds, leaderboard results) and flag them on Flagged for Review.
  5. Store machine copies in data/*.json with source URL + as-of date, so any row can be re-checked.
  6. Never infer: “not listed” ≠ “healthy”; “model output” ≠ “market line”; “correlation” ≠ “causation.”

Methodology references (for the models, not facts)

The Lines Lab math (PF/PA averages, normal win-probability approximation, Pearson r) and the leaderboard gates (CLV, ROI with confidence intervals, out-of-sample testing) are standard quantitative methods implemented transparently on this site. They are our methodology, not NFL-published formulas — which is why every assumption (HFA, SD) is shown and editable. Advanced metrics referenced in planning (EPA, DVOA, Next Gen Stats) are defined by their creators; we do not reproduce their proprietary values without a licensed source (see Q-04).

How to manually review (2 minutes per table)

  1. Open any table → click the row’s source link.
  2. Find the team/game/player on the official page and compare each cell.
  3. If anything differs, note the Flagged ID (e.g. “F-09: BUF PF should be X per [link]”) for the next session.
