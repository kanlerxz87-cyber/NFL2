How to read this page

Each question carries four things: what we already have, what we lack, how the gap closes, and what it blocks. The order is deliberate. A question whose "have" column is empty is not a question about analysis; it is a question about access, and no amount of modelling closes it.

P0 means a decision or a dataset that blocks other work. Everything else waits behind those.

What answering them would change

If Q-101 and Q-103 closed tomorrow, the line lab could price against a benchmark and the availability page could price a replacement in points rather than count bodies. If Q-104 closed, the depth page would stop being a three-club sample. If Q-108 closed, the leaderboard could finally mean something. Until then, the correct output of this project is the register itself, not a certified strategy.
