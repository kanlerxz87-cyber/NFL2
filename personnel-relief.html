Personnel Relief — who replaces which starter, by string

The brief asked the system to know when a club's 2nd, 3rd or 4th-string player has to replace a starter, on offence and on defence. This page is that join, done for every club whose own depth chart could be read from an official page today — and it states, per row, which string each listed player is on, who the club itself names behind him, and how far down that order you can go before you meet another injured player.

Two registers have been in this repository since the first session: the official injury report (nfl.com/injuries), which says who is hurt, and each club's own Unofficial Depth Chart, which says who is behind whom. Neither one answers the brief's question on its own. A name on the injury report with no string is a name; a depth chart with no injury report is a depth chart. This page is the join, and the whole point of it is the third column: the named replacement's own status.

Read the practice code before the string. A Wednesday "Did Not Participate" is a practice status, not a Sunday absence. Five of the eighteen 1st-string non-participants below are not designated Out, and the table says which — a player who does not practise Thursday very often plays Sunday. Anything that prices this signal has to clear G-03 (point-in-time correctness) first, and nothing here is priced: this is a register, not a line.

The deficiency: units where the replacement is also hurt

This is the finding. For each unit below, the club's published order is listed rung by rung and each rung is matched against the official report. A unit that runs out of clean players is a genuine depth problem; a unit whose 1st string is limited but whose 2nd string is clean is a depth problem the club can absorb, and the table distinguishes them without averaging them together.

The clubs that are not covered, and why that is stated rather than hidden

18 of the 28 clubs playing in Week 10 have no depth chart transcribed here. Every one of their rows carries not published in the string columns and names the club chart it lacks, rather than borrowing a chart from another club, inferring a string from a roster's line order, or using a third-party depth chart. The reason is the rule this repository does not bend: a value that cannot be confirmed from an official page stays blank and is flagged.

The uncovered clubs, one row per club and side of the ball. The count is recomputed from the file on every build, so this table cannot go stale the way a hand-written "we cover ten clubs" sentence would.

Extending this to the remaining 18 clubs is the single highest-value data task left in the project, and it is what S-39 already asks for. It was not done in this session because each chart has to be read from the club's own page, the clubs print their positions under different labels (WAS prints DL where SEA prints DT and NT), and a transcription done at speed is exactly the kind of work that produces a confident wrong string. Ten clubs, checked rung by rung, is worth more than 28 clubs transcribed in one pass.
