The re-check in plain language

The injury table is the only dataset that changed, and it changed in a way worth understanding: not by correcting an error, but by publishing more. The standings page — 32 clubs, seven fields each — is byte-for-byte what this repository committed. The Week 10 and Week 11 schedules match on opponent, date, kickoff and neutral site. The depth-chart path still returns the league's 404 page, which is the cleanest possible confirmation of a negative claim.

A superseded dataset is not a failure. Publishing it without a capture time is.
