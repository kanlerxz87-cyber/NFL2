What this build is, and what it is not

Seven trees in this repository publish NFL analysis. They disagree with each other in places, and every one of them was built by an agent session that could not see the others' work. This tree does one job: it re-opens the official league pages, compares them to what is committed here, and writes down the difference. It adds no new model and asserts no new edge.

  • It is a dated record of what the league published, a measured difference against what the repository says, and a decision register.
  • It is not a strategy, a price, or a claim that anything here would win a bet. No price feed exists in this repository and none was reachable.
Every count in this build is measured from a file at build time. If the file changes, the sentence changes with it — that is why the numbers on these pages can be trusted to describe the data and nothing else.
