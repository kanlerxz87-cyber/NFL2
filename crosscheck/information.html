The one entry that changed today

IN-03 and IN-04 were recorded across earlier sessions as unavailable: "no official depth chart exists, so the backup question cannot be answered". That is true of the depth chart and false of the answer. Each official game book carries a starting line-up for both clubs and an explicit Not Active list. The information was always published; it was simply in a PDF rather than on a page.

This is the most useful kind of finding for a project like this one: not a new dataset, but a correction to what we believed was obtainable. It converts a requirement that was marked unmeetable into a parsing job.
