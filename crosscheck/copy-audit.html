Why this page exists

Every one of these is a sentence that was true, or nearly true, when written. The repository already contains a guard that compares prose counts to files — and it caught six of these in an earlier session. These 8 slipped past it because they live in a sibling tree that the guard does not cover, or because they describe a count the guard does not know about.

The fix is not vigilance. It is extending the guard's scope to every tree, which is what this build's own generator does by construction: it cannot print a count it did not measure.
