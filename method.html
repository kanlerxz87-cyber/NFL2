Method

How every number on this site is produced — and where it is weak

No figure on this site is typed by hand into a page. Pages are generated from JSON files, the JSON files are checked by scripts, and the scripts fail loudly. This page states the rules the project follows, so that a reader can decide whether to trust a number rather than having to take it on faith.

The five rules

1. Official sources only. Every value traces to an NFL.com or NFL Football Operations page. No aggregator, no stats site, no model's memory.

2. Never infer. If an official source does not state a value, the cell is blank. A blank is information: it means nobody official said.

3. Prove the mapping, don't assume it. The league's team-stat pages have no header row. Column order is proven by reproducing a known player line and by exact league-wide conservation, not by eyeballing plausibility.

4. Label the model. Anything computed — power ratings, correlations, lines — carries a MODEL label and a formula. It is never dressed as a fact.

5. Publish the failures. Every irregularity goes to Flagged for Review with a severity and a fix. Withheld data is named, not quietly dropped.

What the verifier actually checks

23 data checks, of which 20 pass. The hard ones are structural: every row references two real distinct clubs; the log reproduces all 32 clubs' W-L-T, PF, PA, PCT and net points; streaks re-derive from a chronological scan; the eight conservation identities hold exactly.

9 personnel checks, all passing. These exist because a duplicate position label once caused a third-string player to be scored as a starter — the single most dangerous kind of bug in this project, because it produces a plausible answer rather than an error.

Run them yourself: python3 scripts/verify_data.py and python3 scripts/verify_personnel.py.

The model, stated plainly

Power rating. Each club's points scored and allowed per game, adjusted for the strength of the opponents it actually faced, shrunk toward the league mean by the number of games played. It is a club-strength number in points.

Model line. home_margin = power(home) − power(away) + HFA, with HFA = +0.50 (the neutral-site-excluded estimate). Positive means the home club is expected to win. Sign is asserted, not assumed: the build checks that a power-rating line picks the home side well above 50% and aborts if it does not. Current check: 66.0% correct, PASS.

Win probability. A normal distribution over the model margin with the measured margin standard deviation of 13.27 points. This is a deliberate simplification: real margins are a little fat-tailed, so the model will slightly understate blowout probability.

Pythagorean expectation. Wins expected from points scored and allowed with exponent 2.37, computed per club. The gap to the actual record is the luck score.

Backtest. Walk-forward. For week W the ratings see only weeks < W. Folds are weeks 5–9. Scored by Brier skill against a 50/50 baseline and by log loss; the gates do the rest.

What the model does not do. It does not know about injuries, weather, rest, travel or venue — except that neutral sites are excluded from the HFA estimate. It is a scoring-margin model and nothing more.

Determinism

The analysis uses no random numbers and no clock-dependent logic in its arithmetic. Re-running scripts/analyse.py on the same inputs produces the same output — the build timestamp changes, nothing else. If two runs ever disagree, that is a bug and should be reported.

Known weaknesses

Sample

Nine weeks. 136 games. Thirty-two clubs. Every correlation on this site is estimated on a sample small enough that a single club can move it. The gates exist because of this, and every table prints its own n.

No market

Without odds there is no way to test whether any of this is profitable, or even whether a model line is better than the market's. That distinction — good at predicting versus good at betting — is the one most analytics projects blur.

Depth coverage

Four of thirty-two depth charts. The deficiency analysis is real for those four and blank elsewhere, and the index is a transparent weighting rather than a measured effect.

Transcription

Values are read from rendered pages. The verifier catches arithmetic inconsistency, not a single mistyped digit that happens to preserve an identity. The conservation checks make that unlikely for the team stats and impossible for the game log, but not for every cell.

Every figure on this site is either transcribed from an official NFL source or is explicitly labelled MODEL output. Nothing is inferred. Blank cells mean no official source confirms the value — see Flagged for Review.
