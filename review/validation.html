Every strategy must pass

Validation gates

A strategy is treated as skill-based only if it survives pre-registered, out-of-sample gates and beats a null control after multiple-testing correction. No dataset exists in this repository to run any gate, so every result cell is blank and flagged UNVERIFIED.

Removing luck — nine-step operational definition

StepControlOfficial basisStatusSourceOfficial link
1Freeze hypothesis, features, alpha, minimum N and holdout before looking at outcomesOfficial documentationPROPOSALS12S12 ↗
2Separate public (development) and private (final) evaluation dataOfficial documentationPROPOSALS13S13 ↗
3Exclude future information and test explicitly for leakageOfficial documentationPROPOSALS13S13 ↗
4Score probabilities with a strictly proper scoring rule rather than win/loss countsOfficial documentationPROPOSALS15S15 ↗
5Correct for the number of strategies tried (FWER / FDR)Official documentationPROPOSALS16S16 ↗
6Compare against a null / sham strategy with identical stakingOfficial documentationPROPOSALS13S13 ↗
