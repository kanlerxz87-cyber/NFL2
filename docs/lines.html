Originate Your Own NFL Lines

Methodology + working calculators. Week 11 fair lines are TBD until QIA blockers clear — this page explains how lines will be originated, not what they will be. The calculator below is illustrative only.

1 · What a “line” is (and is not)

  • Spread: Handicap on margin. Favorite −X must win by more than X; underdog +X covers by losing by less or winning. Whole-number spread can push (refund); half-point cannot.
  • Moneyline: Straight winner, margin irrelevant. Minus = favorite (risk to win $100); plus = underdog (win per $100).
  • Total (O/U): Combined points vs number. Whole-number total can push; half-point cannot.
  • Price vs number: The number (e.g. −3.5) and the price (−110) are separate. Standard spread price −110/−110 implies 52.38% each (104.76% total) — the extra ~4.76% is the book’s vig/hold. A line is a price to balance risk, not a score prediction. Sources: GamblingSite — How to Read NFL Odds · OddsShopper — Implied Probability.

2 · Fair-odds math (verified formulas)

Implied prob (American):
  Negative odds:  |odds| / (|odds| + 100)      e.g. −110 → 110/210 = 52.38%
  Positive odds:  100 / (odds + 100)           e.g. +150 → 100/250 = 40.00%

Overround = sum(implied probs) − 100%          e.g. −110/−110 → 104.76% → vig 4.76%
No-vig (fair) prob = implied / sum(implied)    e.g. 52.38/104.76 = 50.00% each (≈ +100)

Expected value per unit staked:  EV = p·b − (1−p)   where b = net odds (decimal − 1)
Kelly fraction:  f* = (b·p − q) / b,  q = 1−p      (maximizes log-growth; use fractional Kelly in practice)

3 · How our fair lines will be originated (pipeline)

  1. Team ratings: Elo-style power ratings from verified results (S-04 baseline), then EPA/success-rate adjustments once play-by-play exists (S-02, Q-15). Home-field value estimated from history (Q-04) — never guessed.
  2. Matchup adjustments: QB starter/backup delta (Q-02), key injuries (Q-01), weather/roof (Q-10, S-07), rest/travel. Each adjustment is a model card entry (S-08) with size + source.
  3. Score distribution: Expected points → spread/total via margin/total distributions calibrated on historical data. Moneyline derived from spread distribution (not a separate guess).
  4. Props: Player expected production from usage (snaps/targets/routes, Q-11) × matchup efficiency. No usage data = no prop line.
  5. Calibration: Out-of-sample log-loss/Brier vs no-vig market baseline (Gate G4). Uncalibrated = TBD.
  6. Publication: Fair spread/total/ML + model card + inputs snapshot. Market comparison only once odds feed exists (Q-03).

6 · Safety guardrails

  • Stake cap 1% per bet until 500 graded bets (S-12); quarter-Kelly thereafter. Never full Kelly on uncertain edges.
  • Loss limits + session stops set before any real-money use (Q-08, Q-17).
