How to use this site

  • Every table row has a Source link. Click it to verify the value at the official source. If a value is blank, it could not be confirmed — it was not guessed.
  • Badges: VERIFIED = checked against official source · UNVERIFIED = conflict / missing · TBD = pending data · DERIVED = calculated from verified inputs (formula shown).
  • Search: Use the filter box above any table to find a team/player instantly.
  • Raw data: All tables are backed by JSON in /data in the repo (e.g. data/standings_2026.json) with source_url per file. Run python3 scripts/validate_data.py to re-check.
