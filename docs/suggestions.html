Suggestions Board — Review Before Anything Changes

Dedicated section for suggestions. No suggestion is implemented until the reviewer marks it Accepted (here + data/suggestions.json + COORDINATION.md). Workflow: Proposed → Under Review → Accepted / Rejected / Deferred.

How to review (decision criteria)

  • Evidence: Does it unlock a QIA blocker (Q-01…Q-20)? Higher priority if yes.
  • Cost/risk: Effort + licensing/legal risk stated per suggestion. High-risk items need explicit approval.
  • Reversibility: Prefer low-risk, reversible steps first (governance, templates) before data purchases.
  • Verification: Any data suggestion must name its official source + timestamp policy. No source = no approval.
