Verification Methodology

How every line was verified, what “verified” means, and how to re-check it yourself. No hallucinations: unverified = blank + flagged.

1 · Verification standard

  • Official first: NFL.com (standings, schedule, stats, news) is the authoritative source for league facts. NFL Media releases outrank third-party summaries.
  • Line-by-line: Every table row was transcribed from the fetched official page and carries a Source link. Click any Source link to verify that row at the origin.
  • Blank, not guessed: If a value could not be confirmed from an official source, it is left blank / “—” and flagged UNVERIFIED or TBD. Never inferred, never filled in.
  • Derived labelled: Any calculation (per-game, Yds/Att, fair odds) shows its formula + inputs and is badged DERIVED.
  • Snapshot dated: Every dataset has a snapshot date. Standings/stats change weekly — re-fetch before deciding.

2 · Steps performed (this pass)

  1. Fetched NFL.com League + Division Standings (2026 REG) → transcribed 32 rows → arithmetic check (PF−PA=Net).
  2. Fetched NFL.com Week 11 Schedule + Nov 9 schedule-change release → transcribed 13 games + 6 byes.
  3. Fetched NFL.com Stats (passing/rushing/receiving/tackles + defense pass/rush) → transcribed top-10s + 32-team defensive totals.
  4. Fetched NFL.com News Roundup (Nov 11, 4 chunks) → extracted key injury/QB items; flagged Week-10-vs-Week-11 timing gap.
  5. Cross-checked backup-QB lists across 5 outlets → found conflicts → marked UNVERIFIED (F-03).
  6. Cross-checked odds/Kelly/correlation formulas across multiple explainers → documented with worked examples.
  7. Built JSON snapshots in /data (each with source_url) → ran scripts/validate_data.py (source present, no blank verified values, arithmetic holds).
  8. Built static site in /docs (no build step) → link-checked internal + external links → deployed via GitHub Pages workflow.

3 · How to re-verify (2 minutes)

  1. Pick any row → click its Source link → find the value on the official page.
  2. Run validation: python3 scripts/validate_data.py (checks sources + arithmetic).
  3. Check snapshot date vs today: if >7 days old, treat as stale and re-fetch.
  4. Check Flagged page for known conflicts affecting that table.
