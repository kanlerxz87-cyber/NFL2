How to use this table

For each strategy, freeze the target outcome, comparator, decision cutoff, sample window, uncertainty method and multiplicity family before collecting evaluation results. The “support” and “change our mind” text is a proposed preregistration aid, not a new numeric gate. Apply the existing registered gates without changing their thresholds. Keep forecast skill separate from staking/realized return; never promote a strategy because a lucky stake sequence did well.

“Missing information” is a discovery checklist. It distinguishes current source links from a complete dataset. No blanks are imputed. The registered blocking-gate text is copied directly from data/strategies.csv; this companion does not reassign gates.
